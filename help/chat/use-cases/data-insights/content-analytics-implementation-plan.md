# Planificar una implementación de Adobe Content Analytics

Descubra cómo la Guía de implementación de ACA en CX Enterprise Coworker crea un plan de implementación de Adobe Content Analytics personalizado, tanto si añade Content Analytics a una implementación de Customer Journey Analytics (CJA) existente como si comienza con una configuración independiente.

## Qué va a aprender

- Cómo el Compañero de trabajo utiliza un proceso de detección guiada para capturar licencias, canales, SDK, datos de comportamiento, vinculación de identidad, privacidad y requisitos de informes.
- Cómo la guía secuencia las fases de implementación, asigna propietarios, identifica dependencias y estima una cronología de ruta crítica.
- Cómo difieren los planes entre una implementación de CJA existente y una implementación de Content Analytics independiente.
- Realizar un seguimiento del progreso, revisar las suposiciones y exportar tareas de implementación a CSV y Jira.

>[!VIDEO](https://video.tv.adobe.com/v/3508620/?learn=on&enablevpops)

## Añadir Content Analytics a una implementación de CJA existente

El primer tutorial comienza con una organización que ya utiliza CJA en la web y en dispositivos móviles. Las etiquetas de Adobe y Web SDK admiten el sitio web, Mobile SDK admite las aplicaciones y la conexión de CJA, las vistas de datos y la secuencia de datos ya existen.

En función de las respuestas, el colaborador elabora un plan que tiene en cuenta todas las tareas necesarias para una implementación correcta y las dependencias que están fuera del control del equipo de implementación.

## Comience con Content Analytics independiente

El segundo tutorial comienza sin una implementación de CJA existente.

El compañero genera un plan que incluye la confirmación de los requisitos de datos de comportamiento con el equipo de cuenta de Adobe y la creación del esquema y el conjunto de datos para los datos de comportamiento web. El asistente guiado crea la conexión de CJA y la vista de datos.

## Seguimiento del progreso y exportación del plan

El vídeo muestra un rastreador interactivo de una página en el que los pasos se pueden marcar como completos, reabiertos o diferidos. El compañero puede actualizar el plan cuando los detalles de implementación cambien y vuelvan a generar sus archivos.

La guía admite otros formatos de exportación, entre los que se incluyen:

- **CSV:** Pasos de implementación con fase, esfuerzo, propietario, dependencias y estado.
- **Jira:** Una estructura lista para pendientes con fases como épicas y pasos como historias, incluidos puntos de prioridad e historia.

## Llave para llevar

La Guía de implementación de ACA en Adobe Coworker convierte los requisitos de implementación en un plan secuenciado y procesable. Al adaptarse al entorno de inicio y mostrar las dependencias de seguridad, privacidad y configuración desde el principio, ayuda a los equipos a coordinar y rastrear un despliegue de Adobe Content Analytics.
