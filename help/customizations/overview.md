# Información general sobre personalizaciones de Coworker {#overview}

Las personalizaciones le permiten ampliar y personalizar Coworker para adaptarlo a cómo funciona su equipo. Use habilidades para estandarizar flujos de trabajo repetibles, integraciones para conectar a Coworker con sus otros sistemas, complementos para agrupar capacidades relacionadas en un paquete instalable y memoria para llevar sus preferencias y estilo de trabajo a través de las conversaciones.
