# Conectar con Shopify {#shopify}

Coworker para equipos le permite conectar su cuenta de Shopify para atraer clientes y segmentos.

>[!PREREQUISITES]
>
>Para utilizar este conector, primero debe tener:
>
>* Una cuenta activa de Shopify
>* El siguiente permiso en Shopify: `read_customers`
>* La URL de la tienda Shopify y el [token de acceso de la API de administración](https://shopify.dev/docs/apps/build/authentication-authorization){target="_blank"} son útiles

## Cómo conectar

1. En la página principal de [Colaborador para equipos](https://coworker-campaigns.experience.adobe.com/){target="_blank"}, haga clic en **Contexto** y seleccione **Conectores**.

   ![Compañero de trabajo para equipos abandonaron la navegación con Contexto expandido y Conectores resaltados](./assets/shopify-1.png)

1. Haga clic en **Agregar integración**.

   ![Botón Agregar integración en la pantalla Conectores](./assets/shopify-2.png)

   >[!NOTE]
   >
   >Si esta no es su primera integración, el botón dirá &quot;Agregar conector&quot;.

1. En la fila Shopify, haga clic en **Conectar**.

   ![Mosaico del conector Shopify con el botón Conectar](./assets/shopify-3.png)

1. Revise el permiso requerido y haga clic en **Continuar**.

   ![Se requiere Shopify para revisar los permisos con el botón Continuar](./assets/shopify-4.png)

1. Escriba su **URL de tienda** de Shopify y **token de acceso de API de administración**. Haga clic en **Conectar**.

>[!NOTE]
>
>En Shopify, obtenga su token de acceso a la API de administración mediante **Configuración** › **Aplicaciones** › **Desarrollar aplicaciones** › **Crear aplicación personalizada heredada** › **Configuración de la API de administración** › **Agregar ámbitos necesarios**.

![Conectar el cuadro de diálogo de Shopify con campos para URL de tienda y token de acceso de API de administrador](./assets/shopify-5.png)

Después de la conexión, Shopify aparece en la lista Conectores.

**Para desconectar:**

1. En la pantalla Conectores, busque el mosaico Shopify y haga clic en **Administrar**.

1. Haga clic en **Desconectar** (no es necesario volver a introducir el token de acceso de la API de administración en este momento).

1. Vuelva a hacer clic en **Desconectar** para confirmar.
